# 创业实验记录模板

## 实验卡

```markdown
### EXP-YYYY-MM-DD-名称

- 阶段：0→1 / 1→10 / 10→100
- 目标假设：如果……那么……
- 风险等级：低 / 中 / 高
- 当前证据：
- 实验动作：
- 目标用户：
- 成功标准：必须观察到什么行为？
- 失败标准：什么结果会推翻假设？
- 截止日期：
- 实际结果：
- 决策：继续 / 修改 / 转向 / 停止
- 后续行动：
```

## 实验规则

- 一个实验尽量回答一个核心问题。
- 成功标准在实验前写，不在结果后修改。
- 优先记录行为、付款、交付和留存，不只记录口头反馈。
- 失败结果也是资产，必须记录其改变了什么决策。
- 实验结束后更新假设栈和下一步优先级。
