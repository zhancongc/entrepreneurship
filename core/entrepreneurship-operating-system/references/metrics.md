# 创业指标参考

## 指标选择原则

指标必须回答一个决策问题：是否继续、是否改变、是否扩大、是否停止。不能因为容易统计就成为核心指标。

## 0→1

- 有效问题访谈数：用户展示真实当前流程的访谈数。
- 样本/数据提交率：愿意提供真实输入的用户比例。
- 首次价值实现率：完成关键任务的试用用户比例。
- 生产集成数：进入真实工作流的客户集成数。
- 付费转化率：发生真实支付或明确采购的比例。
- 首次价值时间：从注册/接入到获得结果的时间。

## 1→10

- 每周活跃付费客户。
- 激活率和 7/30 日留存。
- 试点到正式合同转化率。
- 销售周期和交付周期。
- 客户成功成本和支持工时。
- 续费率、扩容率和流失原因。

## 10→100

- 毛利和贡献利润。
- CAC、LTV、回收周期。
- 渠道转化和渠道依赖度。
- 自动化覆盖率。
- 质量事故率和恢复时间。
- 每个团队/流程的产能和决策延迟。

## API/数据产品北极星候选

> 每周成功完成真实业务查询的付费生产集成数。

这只是候选定义。必须根据客户真实工作流、调用日志和续费行为校准，不能机械使用。
